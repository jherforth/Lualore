# The Obsidian Door Trials

*Ruined obsidian door shrines, restoration puzzles, and a mirror-door boss
arena on a floating island.*

`ruins/obsidian_doors.lua` turns the three `obsidiandoor*.mts` schematics
into a complete gameplay loop that uses nothing but assets already in the
mod and its dependencies.

---

## 1. The concept

Each schematic is a 3x3x3 obsidian cube with:

- a two-tall door on the front face (`doors:door_obsidian_glass_a` with a
  `doors:hidden` half above it),
- a one-deep niche carved behind the door,
- a single everness crystal sitting on top of the cube.

Three material variants exist (decoded straight from the .mts files):

| Variant | File               | Frame                | Crystal                  |
|---------|--------------------|----------------------|--------------------------|
| 1       | `obsidiandoor1.mts`| `caverealms:glow_obsidian` | `everness:crystal_cyan`   |
| 2       | `obsidiandoor2.mts`| `default:obsidian`         | `everness:crystal_orange` |
| 3       | `obsidiandoor3.mts`| `default:obsidian_glass`   | `everness:crystal_purple` |

All three are 3x4x3 including the floating crystal; all door nodes carry
`param2 = 0` and every node/layer is "always place" (no placement
randomness).

## 2. Gameplay loop

### Ruined shrines

The world is divided into a deterministic grid (like villages and ruins).
One candidate per cell, placed in the middle half of the cell, gated by:

- **biome**: only the dry/rugged ruin themes (`desert`: desert, mesa,
  everness:forsaken_desert; `savanna`: savanna, prarie,
  naturalbiomes:outback) — see `ruins/RUINS.md` for the theme definitions;
- **chance**: `lualore_door_chance` (default 0.7);
- **terrain**: the nine footprint columns must be found and near-flat
  (spread <= 4 nodes), no liquid/lava at the surface, at least a partial
  flatness ring around;
- **distance**: at least 48 nodes from every recorded village.

The intact schematic is placed with `place_schematic` (the engine handles
rotation and door param2), then a deterministic, seed-stable share of the
frame blocks (`lualore_door_missing`, default 50%) is hollowed out with a
VoxelManip pass. Two broken pillar stubs and scattered rubble decorate the
site — rubble mixes ruin-theme materials with the shrine's own blocks.

### Restoration

Every solid, non-door cell of the schematic is "requirable". The door
bottoms (`doors:door_obsidian_glass_a`) and the hidden halves
(`doors:hidden`) are **never** required — they are placed intact and are
not craftable by the player. Everything else must match by exact node
name, including the everness crystal on top.

While a player is within 32 nodes of a shrine, a scanner counts the wrong
cells:

- wrong > 0 and within 8 nodes: a throttled hint
  *"The obsidian doorway hums faintly... (N blocks remaining)"*
  (at most once per 5 minutes per player),
- wrong == 0: the shrine **awakens** — particle burst, log entry, and the
  state is persisted. Awakened shrines emit an occasional purple shimmer.

> Tip: if the crystal on top is one of the missing blocks, you will need
> to match its color. The hint counter makes the search painless: place a
> crystal, read the counter, swap colors until it reads zero.

### The mirror island and the Mirror Sentinel

Walking up to an awakened shrine's door (within ~1.7 nodes of the door
cell, at door height) teleports the player to a floating island:

- the island is **generated on demand**, 400-900 nodes away from the
  shrine and 40 nodes around y = 300 — safely below the everness sky
  content (y >= 500);
- it is a 16-node-radius disc built from the shrine variant's materials
  with a sparse glow-obsidian rim, eight broken pillars, and the **mirror
  door**: the same schematic rotated 180°, fully intact;
- the first teleport spawns the **Mirror Sentinel**
  (`lualore:mirror_sentinel`) if it is not already alive.

The Mirror Sentinel is an original model (`models/mirror_sentinel.gltf`,
generated by `tools/make_mirror_sentinel.py`, with a procedural
`textures/mirror_sentinel.png`): a black obelisk core with four mirror
face plates, a spiked crown and four shards orbiting the core, animated
on a single 4-second idle track. It does **not** use `character.b3d`.

Combat facts:

- flying (`fly = true, fly_in = {"air", "ignore"}`), never despawns from
  the fight while you are near;
- keeps its distance (backs off under 3 nodes, closes in beyond 14) and
  reuses the black wizard's blindness curse mechanically — its spells are
  cast through `lualore.wizard_magic.black_do_custom`;
- when idle it drifts back over its island;
- drops depend on the shrine variant: 2-4 of its crystal, mese crystals,
  diamonds.

### Reward and return

When the Sentinel dies:

- a `default:chest` is placed beside the mirror door; it is filled
  immediately by calling the existing loot LBM
  (`lualore:initialize_village_chests`) directly, so the loot table fits
  the biome beneath the island;
- nearby players see *"The Mirror Sentinel shatters! ..."*.

The mirror door returns the player to the shrine they came from (a
persisted per-player return map; a fallback scans for the nearest
recorded shrine). It opens for everyone once the Sentinel is gone — and
**opens on its own 45 seconds after the first arrival** no matter what,
so nobody can get stuck on the island.

## 3. Settings

| Setting                     | Default | Meaning                                    |
|-----------------------------|---------|--------------------------------------------|
| `lualore_obsidian_doors`    | true    | Enable shrine placement                    |
| `lualore_door_spacing`      | 450     | Grid spacing in nodes (200-5000)           |
| `lualore_door_chance`       | 0.7     | Fraction of grid cells that attempt        |
| `lualore_door_missing`      | 0.5     | Share of frame blocks missing at spawn     |
| `lualore_door_boss`         | true    | Spawn the Mirror Sentinel                  |
| `lualore_door_y_max`        | 200     | Search band top                            |
| `lualore_door_y_min`        | -2      | Search band bottom                         |

## 4. Commands

| Command                       | Priv   | Purpose                                        |
|-------------------------------|--------|------------------------------------------------|
| `/spawn_obsidian_door`        | server | Build a shrine at your position (dry biomes)   |
| `/find_obsidian_door [radius]`| -      | Nearest recorded shrine + awakened state       |
| `/clear_obsidian_door_records`| server | Forget records (built shrines stay in the map) |

### Spawning a Sentinel to look at it

`lualore:mirror_sentinel` has a spawn egg (creative inventory, or
`/giveme lualore:mirror_sentinel`). A sentinel placed from the egg has no
`island_key` or `island_pos`, so it does not tether to an island, drops the
default `everness:crystal_purple` instead of the island variant's crystal,
and does not mark any island cleared when it dies. Everything else — flight,
the dogfight attack, the keep-your-distance logic in `do_custom` — behaves
exactly as it does on a shrine. It is a boss (220–260 HP, armor 140, 5 damage
a hit), so pick your spot.

To see it in its proper context instead, `/spawn_obsidian_door` builds a whole
shrine, which spawns a correctly tethered Sentinel once the door is restored.

## 5. API

```lua
lualore.obsidian_doors.build_at(x, z, seed) -- true/false/"retry"
lualore.obsidian_doors.get_records()        -- key -> record table
lualore.obsidian_doors.get_island(key)      -- island table or nil
```

Records live in mod storage under `obsidian_doors`; the return map under
`obsidian_door_returns`.

## 6. Implementation notes

- **Schematic decoding**: MTS v4 stores, after the name table, a zlib
  stream with three planes — `count x u16 BE content id`,
  `count x u8 probability` (127 = always), `count x u8 param2` — in
  `[z [y [x]]]` order. `tools/decode_mts.py` prints any .mts as ASCII
  layers; use it to verify future schematics.
- **Rotation math** mirrors the engine blit (`schematic.cpp`
  `blitToVManip`): rot90 `(x,z) -> (z, sx-1-x)`, rot180
  `(x,z) -> (sx-1-x, sz-1-z)`, rot270 `(x,z) -> (sz-1-z, x)`;
  relative vectors rotate as `(rz,-rx)`, `(-rx,-rz)`, `(-rz,rx)`.
- **Door base offset**: the bottom schematic layer is placed one node
  above the floor (`DOOR_BASE_OFFSET = 1`). If a future edit ever makes a
  shrine sit one node high or low, this single constant is the knob.
- **Chest filling**: LBMs with `run_at_every_load = false` are not
  guaranteed to run on freshly generated mapblocks, so the boss chest
  triggers `lualore:initialize_village_chests`'s action directly (the
  marker field `lualore_loot_filled` keeps it from double-filling).
- **No softlocks**: teleports have a 4-second per-player cooldown, the
  home position is verified open ground in front of the shrine, arrival
  points sit clear of both door trigger zones, and the mirror door has
  its 45-second escape hatch plus a "Sentinel vanished" fallback.

## 7. Regenerating the Sentinel model

```sh
python tools/make_mirror_sentinel.py     # model + texture
python tools/model_extents.py models/mirror_sentinel.gltf   # sanity check
```

Sizes: the model is 28 units tall (2.8 nodes at the entity scale of
10 units = 1 node); the mob renders it at `visual_size 0.85` (~2.4
nodes). The generator self-checks face winding, index ranges and buffer
bounds, and only emits a single animation (`idle`, 4 seconds).
